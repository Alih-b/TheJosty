# The Josty

**Try it!: https://alih-b.github.io/TheJosty/**

## Built with:
[Josty](https://github.com/Alih-b/Josty) — a keyless metasearch CLI, MIT, published
on PyPI as `josty`. It queries public search backends, fuses the rankings, and can
extract bounded text from the pages it finds. No account, no API key, no daemon, no
database.
